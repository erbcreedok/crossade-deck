# Итог рефакторинга: вынос логики картинки приземления

## Что именно переехало
Из сторибук-тестов (`gestureMap.ts` и `gestureScene.ts`) в основной код движка (`game-kit/src/render/landing.ts`) были перенесены сущности, отвечающие за отрисовку силуэта приземления:
- Описание геометрии приземления: `landingBox`, `landingAt` (расчет положения силуэта с учетом зоны и сдвигов).
- Фабрика узла `landingMark`, вместе со всеми комментариями и константой зазора `CARRY_CLEAR = 0.32`.
- Вспомогательные расчеты `zoneFor` (зона, над которой отпустят стопку) и `aimOf` (точка падения).
- Контроль гистерезиса броска: `throwGate` (заменивший хардкод вокруг `flying`).
- Универсальная обертка состояния `landingPicture`, полностью управляющая жизненным циклом картинки приземления через методы `show`, `hide`, `mark`, `end`.

## Изменения и удаление closure-стейта
1. В `gestureScene.ts` стейт, привязанный к замыканиям (переменные `landing`, `parked`, `hidden`, `flying`), был полностью вычищен и заменён на объектный экземпляр `landingPicture`.
2. Функция `throwingNow` была заменена вызовом фабрики `throwGate(wouldFly, THROWN_AT / 2)`. Для сброса стейта теперь вызывается `throwingNow(undefined)`.
3. Завязанность на массив `carried` была убрана из внутреннего состояния: теперь `carried` передаётся как аргумент при вызове `landingPic.show(..., carried)`, чтобы избежать устаревания данных при перехвате (grab).
4. Ошибочно захваченные регулярными выражениями фрагменты `gestureScene.ts` (например, `grabScene`) и комментарии в `gestureMap.ts` (например, перед `GRIP_SPEC`) потребовали ручного поправки через `sed`.

## Состояние слоёв и архитектурные правила
- Изначальный перенос `roundedRect` из `presets` напрямую в `render/landing.ts` вызвал нарушение правила слоёв (`guards.test.ts` блокирует импорты `presets` из `render`). Для устранения конфликта функции `rect` и `roundedRect` с константой `KAPPA` были заинлайнены напрямую внутри `landing.ts` (с использованием `Shape` из `core`).
- На данный момент все тесты `vitest`, включая `testPlan.test.ts` и строгие `guards.test.ts`, полностью зелёные (`97` файлов / `1176` тестов).
- Ручной запуск визуальных тестов контура `contour2.mjs` прошел успешно, картинки сформировались верно.

Архитектура сохранена, `landingPicture` теперь полноправная часть рендера кита, а не побочная логика сторибука.
