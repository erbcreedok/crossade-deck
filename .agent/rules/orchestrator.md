# Оркестрация: откуда берётся задача и куда уходит отчёт

Этот репозиторий ведёт внешний организатор. Ты — исполнитель. Контур один:

- Задача лежит в `.agent/NEXT.md`. Делаешь ТОЛЬКО её — ни шире, ни уже. Если в ней развилка,
  которую нельзя решить чтением кода, — не гадай: остановись и напиши вопрос в `.agent/REPORT.md`
  в раздел «Вопросы», остальное закрой.
- Перед работой прочитай `CLAUDE.md` в корне; работая в `game-kit/` — ещё и `game-kit/CANONS.md`.
  Их правила действуют без исключений (tsc + тесты зелёные до «готово»; никогда не push;
  комментарии — «почему», не история правок; ничего не добавлять сверх просьбы).
- В рабочем дереве могут лежать ЧУЖИЕ незакоммиченные изменения (другой агент в полёте). Их не
  трогать, не откатывать, не коммитить. `git add` — только по явным путям своих файлов,
  никогда `-A`.
- По завершении пиши `.agent/REPORT.md` в форме «закрыто / осталось» с числами из реального прогона
  (какие команды, сколько тестов, что упало). Отчёт без прогона — не отчёт.
- **Комментарии в коде — не твои.** Правя файл, не удаляй и не «сокращай» чужие комментарии: они
  записаны после сломанного правила и стоят дороже кода. Меняй только тот, который твоя правка
  сделала неверным, и только в той части.
- **`.agent/*` не коммитить никогда** — ни `REPORT.md`, ни `NEXT.md`, ни `tmp/`. `git add` только по
  путям из раздела «Коммит» задачи.
- **Сообщение коммита — как в `git log` этого репо**: по-русски, одной фразой о том, ЧТО изменилось
  для стола, без префиксов `feat:`/`fix:` и без имён шагов.
- **`NEXT.md` и `queue/` пишет только организатор.** Ты их читаешь; не переписываешь `NEXT.md`, не
  перекладываешь файлы очереди, не берёшь задачу из `queue/` сам — даже если она кажется
  следующей. Закончил — `REPORT.md` и стоп.
- **`docs/test-plan/*.md` и особенно `README.md` — не через инструмент правки файла.** Дважды твоя
  правка этих файлов ломала UTF-8 (кириллица режется на байтах), задваивала строки и обрывала
  сессию. Числа и строки там меняй одной командой в терминале: `sed -i '' 's/старое/новое/' файл`
  или `python3 - <<'EOF' … EOF` с чтением/записью в utf-8. После правки — `python3 -c
  "open('файл',encoding='utf-8').read()"` как проверка, что файл читается.
