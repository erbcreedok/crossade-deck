# Crossade Deck

Монорепо из четырёх частей, и активно развивается только первая:

- `game-kit/` — КИТ: библиотека пресетов и контрактов для сборки настольных игр. Всё про то, как
  нарисовать стол, пронести фигуру пальцем, довести её до места и перетасовать пачку, живёт здесь.
  Каталог кита — это его документация, и он опубликован:
  https://erbcreedok.github.io/crossade-deck/
- `game-presets/*` — аддоны, собранные НА ките и уезжающие отдельными пакетами: `cards`, `dice`.
  Кит несёт атом и движение, аддон — вид и сами фигуры.
- `apps/*` — стендалон-игры (`klondike`) и `hub`, с которого их запускают. Хаб — одна статическая
  страница; игра внутри неё ленивый чанк, а не второй сайт.
- `server/` — игровой сервер на Colyseus (Express + WebSocket, свои аккаунты). Это старшая
  половина репозитория, её не трогают.

Требования: **Node 22+**, git. Больше ничего — ни базы, ни Redis.

## Как запустить

Репозиторий — npm workspaces с ОДНИМ локом, поэтому ставится всё из корня:

```bash
npm ci
```

```bash
npm run kit                                  # каталог (Storybook)      :9567
npm run dev --workspace @apps/klondike       # косынка отдельно         :9568
npm run dev --workspace @apps/hub            # хаб                      :9569
cd server && npm ci && npm run dev           # игровой сервер           :2567
```

Приложения резолвят `game-kit` и друг друга в ИСХОДНИКИ (условие `development`), так что во время
разработки в репозитории ничего собирать не нужно.

**С телефона по той же Wi-Fi:** дев-серверы уже слушают на всех интерфейсах (`--host`) — открыть
`http://<ip-машины>:9569`. Всё верстается сначала под телефон в портрете.

## Тесты и типы

```bash
npm run typecheck --workspaces --if-present
npm test --workspaces --if-present
cd server && npm test && npx tsc --noEmit
```

Главный набор — китовый, и его план это документ, который держит против набора отдельный тест:
`game-kit/docs/test-plan/`. Тест без строки в плане или строка без теста роняют сборку.

## Деплой

Две аппы на Fly (`crossade-deck-server`, `crossade-deck-hub`) и каталог на GitHub Pages. Образы
собирает GitHub Actions и кладёт в GHCR, выкатываются они оттуда по неизменяемому тегу — сборка и
выкатка это разные решения, из чего и получается откат: он тоже просто выкатка.

Всё про это, включая запуск целиком на своей машине за Cloudflare-туннелем: **`DEPLOY_RU.md`**.

## Как здесь работают

`CLAUDE.md` — карта репозитория и правила, действующие везде; собственные законы кита — в
`game-kit/CANONS.md`. Оба коротки нарочно, и оба читаются до того, как что-то трогать.
