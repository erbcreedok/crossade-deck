# crossade-table — MCP-сервер стола

Через него за стол садится ЧУЖОЙ агент и играет, как человек: `look` — что видно, `moves` — что
можно, `play` — сходить. Правил игры агент не знает и знать не должен: список ходов даёт сервер,
агент называет номер. Чужих карт ему не видно — их не присылает сервер.

## Запуск

```jsonc
// ~/.gemini/config/mcp_config.json — или настройки Claude Code
{
  "mcpServers": {
    "crossade-table": {
      "command": "npx",
      "args": ["tsx", "<путь>/mcp-table/src/index.ts"],
      "env": {
        "TABLE_URL": "http://localhost:2611",
        "TABLE_SECRET": "dev",
        "TABLE_ROOM": "<комната>",
        "TABLE_ME": "agent:antigravity"
      }
    }
  }
}
```

**Только пробный сервер.** На живом столе (`:2590`) гости закрыты, и агенту нужна своя подписанная
дверь — этого пока нет.

Агент садится за стол как гость: сперва открой комнату в браузере его ключом (`TABLE_ME`) или
посади его командой стола, иначе стул ему не принадлежит и ходить будет нечем.
