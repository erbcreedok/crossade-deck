## Что уже стоит

Раздел **Tests/** в сторибуке (порт 9567, `npm run dev` в `game-kit/`) — каталог, проверяющий
себя. Правило одно: **play есть ТОЛЬКО у стори раздела Tests** — открыть страницу и есть
просьба запустить проверки; остальной каталог не играет ничего. Никакого рубильника нет —
он был, провалился как UX и выпилен.

Готовые ступени, обе — образец для следующих:

- `.storybook/stories/TestsNode.stories.ts` — жизненный цикл: узел есть / ушёл / вернулся /
  20 кругов без дрейфа. Точечные пробы пикселей.
- `.storybook/stories/TestsBounded.stories.ts` — коробка: контур единственные чернила; ширина
  растёт — высота нет; квадрат/круг/звезда/путь дают разные узоры; без Bounded — ноль чернил.
  Измерения ПО ВСЕМУ СТЕКЛУ (`snapshot`/`inkOf`/`imagesDiffer`), не точками: штрих в пару
  пикселей между пробами проскальзывает.

Инфраструктура — `.storybook/devtools/checks.ts`: `checks(steps)` (play-обёртка),
`painted(ctx)` (ждёт `Scene.ready` — СОБЫТИЕ, не таймаут), `standing(ctx)` (живая сцена, чтобы
кормить её `setRoot`), `settled()` (2×rAF), `pixelAt`, `snapshot`, `inkOf`, `imagesDiffer`,
`differs`, `waitFor`. Сцена (`devtools/scene.ts`) отдаёт `ready` и регистрируется в WeakMap
(`sceneOf`).

Сторожа: `src/testPlan.test.ts` сверяет план и сьюты В ОБЕ СТОРОНЫ (id теста = первое слово
заголовка; play-шаги ловятся по `name: "play.…"`; `⏳` = «кода ещё нет»; арифметика шапки и
секций пересчитывается). E2E `e2e.checks-run-only-when-asked` держит список ступеней `rungs` —
новая страница Tests обязана попасть туда, иначе её никто не гоняет.

## Очередь работ (слова владельца, не пересказывай — делай)

1. **Tests/Surfaced** — «всё то же самое + бордеры, цвета, размеры, несовпадения размеров
   surface и bounds». Т.е.: заливка на стекле и её цвет; бордер (ширина, цвет, dash) виден и
   меняется; смена surface меняет картинку; surface больше/меньше bounds — расхождение видно
   на стекле.
2. **Tests/Transformable**, **Tests/Container** — той же формой (позы; раскладки).
3. Страницы **Engine**: контур (в т.ч. урок про offset/alignment пунктира — см. git log по
   `src/render/contour.ts`) → реестры → порядок отрисовки (z) → марки.

Припарковано (не начинать без владельца): реестр тем/цветов (обсуждено, ждёт отмашки); три
поворота; `A` (эллиптическая дуга) в `fromSvgPath` возвращает undefined; заметка сцены иногда
показывает устаревшее «nothing is drawn» после прогона — косметика.

## Рецепт новой ступени (проверен дважды)

1. `TestsX.stories.ts` по образцу `TestsBounded.stories.ts`: title `Tests/X`, `gkDoc
   "tests.x"`, шаги `name: "play.x.<claim> — <gloss>"` (id — латиницей, английский, см. сторожа).
2. `preview.ts` → `storySort` → массив после `"Tests"` — добавить `"X"`.
3. Локали `.storybook/locales/pages/tests/{en,ru}.json`: `docs.tests.x` (массив абзацев) и
   `docs.tests.x.<story>`. Оба языка сразу — есть сторож полноты.
4. `docs/test-plan.md`: строки `play.x.*` в раздел INTERACTION, пересчитать `расписано N` у
   секции и шапку «расписано поимённо» (сторож `plan.*` завалит сборку, если соврать).
5. `e2e/catalog.spec.ts` → `rungs` в `e2e.checks-run-only-when-asked` — стори и все имена шагов.
6. Прогон: `npx tsc --noEmit && npx vitest run` в `game-kit/`, затем `npx playwright test`,
   затем ГЛАЗАМИ в браузере: открыть стори, дождаться PASS в панели Interactions.
   «Готово» — только после прогона и с цифрами (см. «Как ломали каталог» в корневом CLAUDE.md).

## Ловушки, каждая стоила времени

- **Крест в начале координат.** Отладочный слой рисует контур И крест в (0,0) коробки. Пиксель
  в геометрическом центре — законные чернила; «внутри пусто» меряется рядом с центром
  (`pixelAt(0.53, 0.53)`). У узла без Bounded креста нет.
- **Dev-сервер не индексирует НОВЫЕ файлы стори.** После создания `TestsX.stories.ts` —
  рестарт сервера и проверка `curl localhost:9567/index.json`, что стори там. Иначе Storybook
  молча откатывает URL на первую страницу.
- **Панель Interactions пуста, если прогон закончился до её подписки** — поэтому в `checks()`
  стоит пауза 800 мс перед первым шагом. Не убирать.
- **Никаких дедлайнов на «сцена нарисовалась»** — только `Scene.ready`: холодный vite-кэш
  держит динамический импорт pixi дольше любого разумного таймаута, а отказ рендерера
  `ready` отвергает мгновенно (и сцена пишет `renderer failed to load` на стекло).
- **После `npm install` — чистый рестарт dev-сервера**: протухший кэш зависимостей vite вешает
  импорт pixi в бесконечность.
- **В e2e к превью — только `page.frameLocator("#storybook-preview-iframe")`**; панели адресуются
  через `&addonPanel=<id>` в URL (клик по вкладке на телефоне мимо).
- Сторожа стиля: английские имена в `name`/id; слово «table» только про таблицу (стол — desk);
  русский — в прозе локалей и в плане.
