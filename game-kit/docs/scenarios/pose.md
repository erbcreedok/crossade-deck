# Сценарий: поза покоя — сторона и угол как ГРАНИ одной позы (видение владельца)

Записано со слов владельца 2026-08-07. Это **эталон поведения**, воспроизводимый на этапе 3.5.
Идентификаторы английские, прозой — по-русски. Каждый пункт «Тогда» обязан стать шагом `play()`
или тестом.

Сторона (`side`) — дискретная грань той же **позы покоя**, что и угол (`angle`), наклон (`tilt`),
позиция. Их резолвит одна **транзакция** (ход нода→нода), и по каждой грани зона делает одно из
трёх: **derive** (из раскладки), **stamp** (навязать фикс), **keep** (взять входящее и хранить).

## Что такое поза и что такое Transform

- **Transform (в полёте)** — позиция, угол, наклон, масштаб, пока ими владеет ЖЕСТ. Локально,
  покадрово, предсказано, по проводу НЕ едет.
- **Поза покоя** — резолвнутый выход транзакции при коммите: `{ slot, position, angle, tilt, side }`.
- **Оседание (`settle`)** — как поза-в-полёте расслабляется в позу-покоя во времени: `snap`
  (мгновенно) или `hold+ease` (подержать, потом кривая). Владеет раскладка зоны, часы одни.

## Стенд: зоны с разными правилами граней

```ts
deckUp    { layout: deckStack, grab: top, facing: { own: "up",   others: "same" } }
deckDown  { layout: deckStack, grab: top, facing: { own: "down", others: "same" } }
board     { layout: grid, grab: one, facing: { own: "up", others: "same" }, angle: "derive", keeps: ["drag","flip"] }
discard   { layout: heap, grab: top, facing: { own: "down", others: "same" }, keeps: ["drag"] }
table     { layout: free, grab: one, facing: { own: "keep", others: "same" }, angle: "keep", keeps: ["drag","flip"] }
straight  { layout: free, grab: one, facing: { own: "keep", others: "same" }, angle: "stamp:0", settle: "hold5s+ease" }
hand@u1   { layout: fan, grab: one, facing: { own: "keep", others: "back" }, angle: "derive", owner: "u1", hot: phantom }
hand@u2   { layout: fan, grab: one, facing: { own: "keep", others: "back" }, angle: "derive", owner: "u2", hot: phantom }
```

Ни машины состояний, ни уровней приоритета, ни флагов-отрицаний: у каждой зоны по грани — одна
запись derive/stamp/keep.

## A. Взятие из колоды в руку (грань `side`)

- **Дано**: тяну верхнюю карту из `deckDown` (закрытой) в `hand@u1`.
- **Тогда** (в полёте): карта летит рубашкой — груз в drag-корне несёт свою сторону, отдельного
  правила для полёта НЕТ.
- **Тогда** (после коммита): владелец видит лицо, остальные рубашку (`others: "back"`).
- **Дано**: то же из `deckUp`.
- **Тогда** (в полёте): летит лицом — по той же причине, без единой новой строки.

## B. Приход в зону-штамп (STAMP по `side`)

- **Дано**: карта любой стороной попадает на `board` → лицом вверх, история игнорируется.
- **Дано**: карта попадает в `discard` → рубашкой вверх. Ручной переворот в сбросе НЕДОСТУПЕН
  (`keeps: ["drag"]`) — вынести можно, вертеть на месте нельзя.

## C. Перенос угла между бордами (KEEP по `angle`)

- **Дано**: на `board` взял карту и покрутил её на 15° под пальцем (это Transform, в полёте).
- **Когда** переношу на `table` (`angle: "keep"`).
- **Тогда**: карта ложится под теми же 15°. Угол теперь В СОСТОЯНИИ карты, едет по проводу.
- **Тогда**: игрок C, зашедший ПОСЛЕ переноса, видит те же 15° — он читает состояние, а не
  траекторию. Сервер после реконнекта тоже: угол keep-грани хранится.
- **Дано**: тот же перенос на `board` (`angle: "derive"`).
- **Тогда**: 15° теряются, карта выпрямляется по сетке — раскладка ДИКТУЕТ угол, входящий игнорится.

## D. Автовыпрямление — STAMP плюс оседание

- **Дано**: кладу повёрнутую карту на `straight` (`angle: "stamp:0"`).
- **Тогда** (кейс А, `settle: snap`): мгновенно встаёт в 0°.
- **Тогда** (кейс Б, `settle: hold5s+ease`): лежит под входящим углом ~5 секунд, затем медленно
  едет в 0°. Поза покоя в ОБОИХ кейсах одна — 0°; различие ТОЛЬКО в кривой оседания.
- **Тогда**: поздний зритель видит карту там, где её застаёт истина (0° или на пути к нему) —
  анимация оседания декоративна, покой авторитетен.

## E. Зона-хранитель БЕЗ продавливания через след

- **Дано**: карта попадает на `table` → остаётся как лежала (`own: "keep"`).
- **Дано**: со `table` карту возвращают в `deckDown`.
- **Тогда**: ложится рубашкой — по дефолту КОЛОДЫ. Продавливания «стол перебивает колоду» через
  `from` НЕТ: транзакция не читает траекторию.
- **Дано**: игра ХОЧЕТ, чтобы карта со стола сохраняла сторону в колоде.
- **Тогда**: это пишется через СОСТОЯНИЕ, не через след — стол при укладке ставит факт
  `el.faceFixed = el.side`, колода регистрирует свою `own`, читающую `el.faceFixed`. Факт едет и
  одинаков у всех; траектория жила бы только у видевшего перенос.

## F. Кастомный `own`, читающий состояние стола (перебивка правил зоны)

- **Дано**: песочница с тумблером «открытый стол» в общем конфиге.
- **Когда** тумблер включён.
- **Тогда**: `deckDown` ложит карты ЛИЦОМ, хотя её запись говорит `down` — кастомная `own` читает
  `ctx.config.openTable`. Правило стола перебило правило колоды, функция осталась чистой.
- **Дано**: покер, фаза `showdown` на столе.
- **Тогда**: рука (`own: "keep"`) на фазу показывает лицо всем — `own` читает `ctx.chain.board.phase`.
  Рука физически лежит НА столе, поэтому цепочка контейнеров ей доступна. Ни флага на карте, ни
  машины состояний.
- **Тогда**: и то, и другое воспроизводимо у позднего зрителя — конфиг и фаза в общем состоянии.

## G. Ручной переворот и сброс истории (грань `side`, два бита)

- **Дано**: карта на `board` лицом вверх, переворачиваю рукой → рубашкой; все видят одинаково
  (`others: "same"`).
- **Дано**: увожу на `table`, возвращаю на `board` → снова лицом: `board` штампует на входе, чем бы
  карта ни была. Механизма «сброс ручного переворота» не требуется — следствие одной строки STAMP.

## H. Относительный показ — АЛЬТЕРНАТИВА, не замена (грань `side`, ось `others`)

Переключаю руку на `others: "opposite"` (Ханаби, карты держат лицом наружу).

| Действие | Владелец видит | Остальные видят |
|---|---|---|
| исходно | лица | рубашки |
| перевернул ОДНУ карту | у неё рубашку | у неё **лицо** |
| перевернул руку ЦЕЛИКОМ | у неё лицо, у прочих рубашки | у неё рубашку, у прочих **лица** |

- **Тогда**: «странная» карта остаётся странной ВСЕГДА. Два бита не смешиваются:
  `сторона у владельца = card.side XOR zone.flipped`.
- **Тогда**: механика сама себя обозначает — владелец видит рубашку среди лиц, стол лицо среди
  рубашек. Отдельного маркера не заводить.
- **Дано**: та же рука с `others: "back"` (строгая игра) → тот же переворот прячет карту ОТ ВСЕХ.
  Одно действие, разный смысл, разница — в одной записи реестра.

## I. Раздача кривой рукой (жест задаёт `card.side`)

- **Дано**: раздаю из `deckDown`, первую карту фликаю рубашкой вверх.
- **Тогда**: получатель видит её лицом (его `own: "keep"` от `card.side`), мы рубашкой.
- **Когда** следующую фликаю ЛИЦОМ вверх (альтернативный жест, «кривые руки»).
- **Тогда**: `card.side` этой карты установлен жестом в противоположный — получатель видит рубашку,
  мы лицом. Сторону задал ХОД (ориентация жеста в момент отпускания), а не зона; она уехала в
  состояние, поэтому картинка сходится у всех, включая C.
- **Тогда**: зона-получатель — `keep`, поэтому принимает принесённую сторону. Была бы `board` — она
  бы заштамповала, и кривизна руки ничего бы не изменила.

## J. Когда происходит переворот

- **Тогда**: карта кладётся в указанное место СРАЗУ со старой стороной; переворот — по эху сервера.
  Позиция и угол derive-граней обратимы, `side` — нет: мигнуть лицом и спрятать читается как глюк.
- **Тогда**: ожидание сервера НЕ индицируется. Три точки зарезервированы за ожиданием ЧЕЛОВЕКА;
  неперевёрнутая карта — уже сообщение.
- **Тогда**: при отказе сервера карта улетает домой, ни разу не показав лица. Правило одно на ВСЕ
  перевороты, включая ручной тап.

## Что из этого следует для модели

1. **Транзакция — спина**: `Move`/`Flip`/`Rotate-commit` — не сущности, а «какие грани позы непусты».
   Осколки (`DragPayload`, `PendingRequest`, `AcceptRule`, `layout.place`) — её части.
2. **Сторона и угол — одна семья** (грани позы), а не две. `facing` — правило грани `side`.
3. **derive/stamp/keep** по каждой грани заменяет и «штамп», и «хранитель», и продавливание через
   `from`. `from` из правила уходит совсем.
4. **keep-грани едут по проводу** — осознанное исключение из «едет только containment». Платит
   только `free`-раскладка; сетка и веер остаются derive и бесплатны.
5. **Оседание отделено от позы**: кейс А и Б делят покой 0°, различаются `settle`. Анимация
   декоративна, покой авторитетен.
6. **Кастом читает СОСТОЯНИЕ, не траекторию**: `ctx.chain`, `ctx.config`, `el.faceFixed` — едут и
   одинаковы у всех; `from`-след жил бы только у видевшего перенос.
7. **`own`/`others` — ДВА реестра**, оба чистые функции; настройка их игроком — правило игры (едет,
   авторитетна), а не доступность (четырёхцветность локальна, ибо меняет ЛИЦО, а не сторону).
8. **Два бита XOR** (`card.side` / `zone.flipped`) — «странная» карта странна навсегда без
   спецкода. `handOpen` из client1 — значение `others`, не механизм.
