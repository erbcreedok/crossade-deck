## UNIT · ShadowCaster и Lit — тень и единственный свет

`vitest` · 7 кейсов, расписано 7

Тень — НЕ узел: это слой, который план рисует одним проходом под всем покоящимся
(`docs/design/camera.md`). Атом несёт один выбор — какой контур падает (`from: footprint |
silhouette`); свет — корневое поле `Lit.light {frame, angle}`, одна лампа на холст, направление
падения — одна формула в одном месте (`lightVector`). Кастование ВЫВОДИТСЯ: покоящийся стек — один
кастер, отцепленный ребёнок кастит сам; переставили в дереве — вот и весь переключатель.

| id | Дано | Когда | Тогда |
|---|---|---|---|
| `atom.shadow.names-its-contour` | узел с атомом; с `from: footprint` | поле прочитано | дефолт `silhouette` — тень нарисованной фигуры и есть её силуэт; `footprint` — голая коробка |
| `atom.shadow.a-resting-stack-casts-once` | стопка с атомом, карта с атомом внутри | `castsShadow` до и после `remove` | внутри стопки карта НЕ кастит (ближайший кастующий владелец говорит за поддерево); отцепленная — кастит сама, без единого флажка |
| `atom.shadow.no-atom-no-shadow` | узел без атома | `castsShadow` | false: отсутствие способности и есть отказ, выключателя нет |
| `atom.lit.defaults-to-the-viewer-frame` | корень БЕЗ `Lit` | `lightVector` | сток-лампа сверху-справа КАДРА: падение вниз-влево, вектор единичный — потребитель без мыслей о свете получает свет, а не кастеров без теней |
| `atom.lit.the-angle-turns-the-fall` | `Lit` с углом 0; с углом 180 | `lightVector` | свет с +x бросает тень ровно в −x; с −x — в +x: одна формула, второго места с направлением нет |
| `atom.lit.the-viewer-frame-ignores-the-camera` | два корня: frame viewer и world, угол 0 | `lightVector` с поворотом камеры 90 | viewer не заметил поворота (падение постоянно на ЭКРАНЕ); world повернул падение на −rotation — лампа осталась над столом |
| `atom.lit.reads-at-the-root` | лампа на корне, «своя» лампа на ребёнке | `lightVector` через ребёнка | отвечает КОРНЕВАЯ: свет один на холст, пер-предметного света не существует |
