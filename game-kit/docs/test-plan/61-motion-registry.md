## UNIT · реестр анимаций — вид, который дизайнер назвал сам

`vitest` · 22 кейсов, расписано 22

Глаголы движка — это МЕХАНИКИ, и их список закрыт: переворот коммитит сторону, тасовка — порядок,
бросок кончается там, где скажет физика. **Вид** ничего не коммитит: он говорит «сюда», «нельзя»,
«молодец» — и закрытого списка таких быть не может, потому что это словарь дизайнера, а не движка.
Отсюда реестр (`registerMotion`) и один глагол, который его играет (`animate`).

Форма взята с реестра тасовок намеренно: рецепт — чистая функция `(i, n, t, rest) → Transform`, её
крутят те же единственные часы, и рантайм никогда не узнаёт, какой рецепт он держит. Один закон
переезжает вместе с формой и здесь проверяется по всему реестру разом: **на `t = 1` рецепт возвращает
`rest` ТОЧНО** — иначе каждый показ кончается рывком, а вслед за ним доводкой, которой никто не звал.

Одно расхождение с тасовками — сознательное. Неизвестное имя тасовки падает в `riffle`, потому что
перестановка обязана выглядеть хоть как-то. Неизвестное имя анимации не играет НИЧЕГО: стокового вида
для опечатки не существует, а дрожь на месте заказанного «ура» — это баг, который сам себя прячет.

`keyframeMotion` — ответ на вопрос «а свою как?»: таблица поз данными, каждый канал — СМЕЩЕНИЕ от места
и в собственных осях фигуры, пауза — два ключа с одним значением. Концы таблицы прибиты к месту
конструктивно, поэтому первый закон нельзя сломать никакой набранной таблицей.

| id | Дано | Когда | Тогда |
|---|---|---|---|
| `motions.registry-round-trip` | свой рецепт | `registerMotion` → `motionRecipe` → `motionNames` → `resetMotions` | тот же объект обратно, имя в списке, после сброса список пуст |
| `motions.unknown-name-is-nothing` | сток установлен | спрошено имя, которого нет | `undefined`. Расхождение с тасовками — стокового вида для опечатки нет |
| `motions.every-stock-look-ends-on-the-seat` | весь реестр | у каждого имени взята поза на `t = 1` | ровно `rest` — поворот и размер включительно. Проверено падением: вид, уезжающий на тысячную единицы, ловится |
| `motions.shiver-swings-sideways-and-decays` | `shiverMotion` | взяты гребни первого и второго циклов | ноль на первом кадре, второй гребень меньше первого; `rides` не поднят — ехать некуда |
| `motions.shivers-default-swing-is-visible` | дефолтная дрожь | измерен гребень | больше двадцатой доли единицы и меньше пятой. Незаметная анимация и отсутствующая на скриншоте неотличимы |
| `motions.bounce-goes-up-the-screen-and-rides` | `bounceMotion` | взята вершина дуги | `y` меньше — вверх по экрану; высота ровно как заказана; `rides` поднят — тень едет следом |
| `motions.spin-lands-facing-home` | `spinMotion` двумя оборотами | взята середина | целый оборот пройден, фигура смотрит домой и раздута прыжком; начало координат не сдвинулось |
| `keyframe.keys-are-offsets-from-the-seat` | одна таблица | сыграна на двух разных местах стола | смещение одно и то же — таблица переносима, потому что говорит о смещении, а не о координате |
| `keyframe.ends-on-the-seat-whatever-was-typed` | таблица, кончающаяся далеко от места | взята поза на `t = 1` | ровно `rest`. Закон нельзя набрать мимо: концы прибиты конструкцией |
| `keyframe.a-pause-is-two-keys-the-same` | два ключа с одним значением | взята середина между ними | держит. Отдельного слова `hold` нет — пауза ЕСТЬ отрезок без изменения |
| `keyframe.keys-are-read-in-order-however-they-were-typed` | ключи вперемешку | сыграны | по возрастанию `at`. Порядок строк в таблице — не смысл |
| `keyframe.a-segment-may-name-its-own-easing` | одна таблица с `ease` и без | сравнены середины | отрезок со своей кривой обгоняет; ощущение задаётся раз и оспаривается по отрезку |
| `keyframe.a-zero-width-segment-is-a-jump` | два ключа на одном `at` | взята эта точка | побеждает дальний — скачок написан намеренно и читается однозначно |
| `keyframe.carries-the-phases-it-was-given` | таблица с `commitAt`/`beats`/`rides` и без | прочитана запись | фазы донесены до рантайма; у простого вида их нет, и рантайм подставляет свои |
| `motions.a-look-never-asks-what-it-is-moving` | рецепт-соглядатай | вызван | получил только индекс и число. Узла ему не дают — потому один вид играет и на карте, и на кости |
| `animate.plays-a-registered-name` | стоковый `bounce` по имени | четверть спана, затем весь | вверх на гребне, ровно на месте в конце, часов больше не просит |
| `animate.unknown-name-plays-nothing` | имени нет в реестре | вызван `animate` | не бросил, ничего не подал, кадра не заказал — вид украшение, он не может уронить ход |
| `animate.holds-the-node` | вид играется | спрошен `busy` | занят, пока идёт, свободен после — палец должен знать, что перебивает |
| `animate.durMs-replaces-the-span-and-rate-scales-it` | один вид | `durMs` абсолютом, затем он же при `rate: 2` | спан заменён; ставка умножает поверх — сцена замедляет всё, не зная длительности ни одного |
| `animate.a-nonsense-rate-is-ordinary-speed` | `rate: 0` | сыгран | обычная скорость. Ноль — не стоп-кадр, а ошибка, и делением на ничто она не становится |
| `animate.a-recipe-plays-without-being-registered` | таблица прямо в вызове | сыграна | реестр — удобство, а не пропускной пункт; закон таблицы держится и через рантайм |
| `animate.a-looks-phase-commits-once` | вид с `commitAt` и `beats` | три кадра поперёк фазы | коммит ровно один, доля отбита один раз — контракт переворота, выданный чужому виду |
