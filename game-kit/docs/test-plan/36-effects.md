## UNIT · the effects list — the runtime seam

`vitest` · 5 кейсов, расписано 5

Один шов, через который движок домешивает РАНТАЙМ-слой: список маленьких функций, каждая отвечает
«подменяю узел / сдвигаю позу / кладу coat». Ядро складывает список вслепую и ни одной механики не
знает по имени — `flippable` и `coated` регистрируются в него сами. Свёртка чистая, гоняется юнитом.
Дизайн — `docs/FLIPPABLE-HANDOFF.md` §4.

| id | Дано | Когда | Тогда |
|---|---|---|---|
| `effects.empty-is-the-node` | список пуст | `applyEffects(n, ctx)` | тот же узел, поза IDENTITY, coats нет |
| `effects.pre-composes` | два эффекта, каждый сдвигает позу | `applyEffects` | `pre` — композиция обоих сдвигов по порядку |
| `effects.node-chains` | эффект подменяет узел | следующий эффект | видит подменённый узел, не исходный |
| `effects.coats-accumulate` | два эффекта дают coats | `applyEffects` | все coats доезжают, первый-зарегистрированный первым |
| `effects.order-is-registration` | три эффекта | `applyEffects` | выполняются в порядке регистрации |
