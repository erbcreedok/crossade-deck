## 0. Переключатель ночных сборок (чекпоинт-инфраструктура)
- После каждой фичи клиент стола этой сборки сохраняется на Мак: `data/builds/<build>/` (исходники table-client +
  то, что он импортирует из src, на момент коммита — через `git archive` тега).
- `?build=<n>` в адресе стола (и на `/t` реле — проброс) → клиент собирается из сохранённой папки; без него — последний.
- В окне настроек — список ночных сборок; тап — перезагрузка в выбранной; номер внизу окна.
- Ограничение: сервер всегда последний. Фичи, меняющие сервер, помечаются «меняет сервер».
