## Ловушки, найденные в работе (не переоткрывать)

- Тикер движка спит: прямые мутации элементов из консоли/e2e требуют `rt.wake()`.
- Плейрайт-скриншоты падают в `/Users/giyers/`, не в cwd.
- Песочница в e2e: `window.__sandbox` (BoardScene), `testHooks()` — экранные координаты;
  `nodeStore.get(id).body.px` — контентные. Зеро-дистанс драг (карта уже в точке дропа) даёт
  ложный «провал» теста — сначала переставить карту.
- `board:N` — свободные стопки в круге, `board:0` — колода, `table:0` — центр. Дроп мимо круга
  (760×760, форма circle) → карта летит домой, это норма.
- Магнит читает спринг-таргет (`CardBody.targetX/Y`), не `px` — иначе залипает навсегда.
- vitest-фильтр по пути иногда «не находит файлов» — гонять `npm test` целиком.
- **Снимок приходит В КОНСТРУКТОР.** `onStateChange` отдаёт текущее состояние СИНХРОННО при подписке
  («как при джойне», localTable.ts) — а конструктор базы выполняется раньше полей наследника. Пока
  `bindRoom` стоял в конструкторе, первый же снимок падал в недостроенный стол (`pending` ещё нет).
  Подписка теперь в `NetTableScene#mount`; заводить её раньше нельзя.
- **Слои хрома/сцены существуют только после `mount`.** Всё, что зовёт `chromeAdd`/`surfaceAdd`
  (надписи, HUD), собирается в `buildScene`, а не в конструкторе — иначе `undefined.addChild`.
  Обе ловушки tsc и юниты пропускают: ловит только браузерный смоук.
- `localTable.ts:119` держит разделитель СЫРЫМ байтом NUL (`join("\0")` символом, не escape'ом) —
  grep считает файл бинарным и молча ничего не находит. Искать по нему только с `grep -a`.
- Дефолтная `grep` в shell-снапшоте сессии может глушить вывод — надёжнее `command grep`.
