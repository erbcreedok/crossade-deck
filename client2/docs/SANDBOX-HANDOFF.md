## Что построено (карта)

**Модуль песочницы `src/game/sandbox/`** (конфиги фичи НЕ в общих модулях — требование владельца):
- `settings.ts` — SandboxSettings (форма/рассадка/слоты/стопки/посадки/колода 36|52), дефолт:
  ВСЁ круг и динамично, **одиночный режим (seats 1, никаких фантомов «Игрок N»)**; строки меню +
  цикл значений. `board.ts` — `sandboxBoard(settings)` → билдер `boards/library/roundTable.ts`.
- `menus.ts` — реализация шва `SceneMenus` (DIP: generic-BoardScene настроек НЕ знает, он просит
  строки у хоста; смена значения → `scene.reconfigure(spec, seats)` + `boards/migrate.ts`
  пересыпает карты без потерь). `live.ts` — подключение к `sandbox_room`, оборачивает комнату в
  ТЕ ЖЕ контракты BoardDriver+PresenceHub; `liveSeats.ts` — рассадка КАЖДОГО снимка из ростера
  комнаты (авторитет по стульям один; мок-фантомов в live нет).
- Хост `src/PlaygroundBoard.tsx` — тонкий React над канвасом: ВЕСЬ игровой UI канвасом
  (доктрина!), HTML только «← меню». Live-кнопка/бейдж «ник · комната КОД»/«код…»/«выйти» —
  chrome-инструменты сцены (`BoardSceneOptions.tools` + `setBadge`); ввод кода — временно
  `window.prompt` (канвас-инпут — отдельная задача).

**Generic-борда (`boards/`)**: `radial`-раскладка (динамика, `min` = мест — задаёт РАЗМЕР круга,
заготовок-«шариков» нет), `shape:"circle"` (рамки и СЛОТЫ кругами; grid намеренно прямоуголен),
круглый стол с free-боксом в центре посадок; подсветка дропа — по форме зоны, в live — цветом
игрока. Контекстные меню: long-press по пустому (роутер: третий исход press) / ПКМ (правая
кнопка жестов НЕ начинает); колода — перемешать(«шурух», `shuffleFx.ts`)/раздать по 2
(`dealPlan.ts`: пара 0.09с, между игроками 0.26с, пустые пропускаются)/размер колоды; карта —
поворот 90°/флип; фикс-дропзоны при драге (`ui/DropBar`, chrome, без тени, живут только в драге).
Тап-драг = верхняя карта, hold = колода блоком.

**Live**: сервер `server/src/SandboxRoom.ts` — комната-ретранслятор («клиент считает — сервер
раздаёт»: cmd+готовый снимок, поздним гостям последний снимок), лок «кто первый схватил»,
курсоры, профиль-цвет (если свободен), 12 max (дальше matchmaker откроет новый рум), аноним →
«Красная панда» (`sandboxNames.ts`), аккаунты client1 как есть, welcome по рукопожатию `hello`
(иначе colyseus.js роняет сообщение до onMessage). Сплит-витрины: Mechanics/Boards → Round
table / Sandbox live; Stack interactions → Deck actions.

**Выделение/присутствие — атомы (`ui/selection.ts`, `ui/PresenceCursor.ts`, `kit/figureGlow.ts`)**:
- glow = способность элемента (`Glowable.setGlow`), устроен КАК ТЕНЬ: часть фигуры — rect
  (карта), круг (фишка) или СОБСТВЕННЫЙ силуэт (`silhouetteExtract`, снята и БЕЛАЯ версия — tint
  по рисунку грязнил) — конь светится конём. Союз — рендером: dilate (веер копий) + erase точных
  форм, кеш в текстуру. НЕ привязывать фигуру к части: `watchFigureGlow` — контур слоем сцены,
  уехавшая часть РВЁТ силуэт и светится лично, вернулась — срослась (витрина UI-kit/Selection —
  живая). В сцене: светится ровно то, что держат (одиночная — одна; свой блок-драг — фигура).
- Акцент: в live ВСЁ своё — цветом игрока (профиль-бейдж, свой курсор-точка, подсветки дропа,
  hot дропзон, рамка своего захвата); в соло — прежнее золото.

**Свободный дроп (2026-08-05, коммит f4b00af)**: карта, брошенная в круг стола (мимо колоды и
центра), остаётся где и какой стороной положили — слоты `board:N`, позиции локальные
(`FreePositions` в дереве, как сдвиг колоды-блока); в колоду можно класть (из руки/центра —
стороной колоды, со стола — как лежала). Подсветка по приоритету: колода/стопка → её футпринт,
центр → центр, пустой бокс → весь круг (псевдо-цель `zone:box`). Правила стороны/ключей/клэмпа —
чистый `boards/freeDrop.ts` под тестами. Блок-драг и меню «колода» — только слот 0.

**Стол одинаков у всех (2026-08-05)**: позиции свободных стопок, сдвиг колоды и оверрайды карт
(поворот/лицо) переехали В СОСТОЯНИЕ (`BoardState.free` / `BoardState.fx`) — live и поздние
гости получают их снимком даром, сервер не менялся. Команды порта: `placeFree`, `offsetFree`,
`cardFx`; `move` везёт `at` (точку свободного дропа) и `face` (отсутствие поля СНИМАЕТ оверрайд —
зона решает сама). Старые снимки нормирует `ensureVisuals` (live.ts).

**Настройки синкаются в live (2026-08-05)**: меню зон живёт и в live — смену применяет СЕССИЯ
(`live.changeSettings`: миграция снимка + `room.send("settings")`), сервер ретранслирует и держит
`lastSettings` для welcome поздним гостям; сцена получает готовую спеку через `applySpec` (драйвер
не трогается). Посадки в live заперты (`lockSeats` — места раздаёт комната).

**Драг виден всем (2026-08-05)**: позиция таскаемой карты стримится каналом присутствия
(`PresenceHub.drag`, сообщение `drag` — ретрансляция без хранения, темп курсора 50 мс); зрители
ведут карту спрингом к точке, rebuild её не дёргает, конец стрима/выход игрока — карту ведёт
снимок. Блок-драг колоды стримится той же строкой с флагом `block`: зрители двигают всю стопку
одной дельтой от домов (форма цела). Presence-визуалы сцены (glow локов, курсоры, ведение чужих
драгов) — коллаборатор `boards/scenePresence.ts` (композиция, шов PresenceSceneHost); «что под
точкой»/«что светить» — чистый `boards/sceneAreas.ts` под тестами; scene.ts 1150 → 996 строк.

**Движок как сервис (2026-08-05)**: наследование сцен от SceneEngine УБРАНО у всех пяти сцен
(boards/solitaire/multiplayer+live/crossade/kit) — теперь композиция через engine/sceneRuntime.ts:
SceneDelegate (бывшие вирт-швы; нереализованный шов = поведение ядра) + SceneApi (бывшие
protected-поля/хелперы, включая дефолт-ветки defaultBeginDrag/CanDrag/PickElement/SceneTap).
Protected-контракт SceneEngine теперь ВНУТРЕННИЙ (только SceneRuntime); слияние двух классов в
один файл — косметика на потом. Новую сцену писать ТОЛЬКО делегатом.

## Ловушки (кровью)
- `.env.local` держит LAN-IP машины — ПРОТУХАЕТ при смене сети (66→88 уже ловили): live висит на
  «подключении», лечится правкой IP + рестарт vite. Файл не коммитить.
- Витрины: НЕ мерить фигуры по `root` элементов в build стори — тела ещё не синканы (нули);
  позиции — из раскладки (`resolveLayout`) или через `watchFigureGlow`.
- Правая кнопка: жесты не начинает (sceneEngine.onDown фильтрует button 2) — не «чинить» обратно.
- `onButtonUp`: отпускание ДО click() — click может снести кнопку (строка меню).
- Кэноны владельца: игровой UI ТОЛЬКО канвасом; модуль на фичу, generic-слои без знания о фичах;
  «готово» — после прогона в браузере с цифрами; неоднозначный фидбек — ПЕРЕСПРОСИТЬ, не
  додумывать; план дня — в GitHub issues/project («Crossade Deck — доска»), статусы двигать.
