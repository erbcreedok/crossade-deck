# Правила каталога и визуальной модели

Всё, что ниже, — требования владельца, высказанные в работе. Каждое появилось после того, как было
нарушено. Список нужен, чтобы не выяснять их заново: правило без записи и без теста живёт до первой
пересборки контекста.

Колонка «сторож» — чем правило держится сейчас. `—` значит «ничем, держится только вниманием».

## Каталог: панель и код

| правило | сторож |
|---|---|
| `name` — настоящее имя свойства, английское. Русский только в `description` | `argNames.test.ts` (весь каталог: имена вычитываются из исходников стори) |

| Тип печатается, только если он ЧТО-ТО СООБЩАЕТ: союз у списка выбора. `boolean` у тумблера и `number` у слайдера — шум, `string` у списка из четырёх вариантов — ложь | `argTable.test.ts` |
| «Show code» печатает код КОМПОНЕНТА с аргументами этой стори, а не исходник стори и не пересказ JSX | `storySource.test.ts` |

## Модель: высота (`z`)

| правило | сторож |
|---|---|
| Две оси и обе названы: ЭКРАН (x, y — место на столе, Y растёт вниз) и ВЫСОТА (`z` — к зрителю, 0 у лежащего) | `plane.test.ts` |
| `z` — источник; экранный подъём и тень — следствия. Ничто не двигает предмет по экрану «чтобы выглядел выше» | `plane.test.ts` |
| Высоту даёт только то, что МЕНЯЕТ РАЗМЕР предмета. Idle-дыхание размера не меняет → это экранная декорация, а не высота | `plane.test.ts` |
| `z` есть у каждого элемента как свойство. У всего, что лежит на столе, — 0 | `tableElement.test.ts` |
| Подъём в полёте (`move.lift`) — высота, а не сдвиг позиции: иначе тень летит по той же дуге и перспектива пропадает | `moveStyles.test.ts` |

## Модель: поза и дыхание

| правило | сторож |
|---|---|
| Ось зовётся `pose`, а не `rest`: `rest` — одно из её ЗНАЧЕНИЙ, и `rest: "rest"` не читается | `plane.test.ts` (скан исходников) |
| Значения позы — `rest` / `lifted` / `held`. Не `floating`: это читается как имя анимации, а поза — состояние | `plane.test.ts` (скан исходников) |
| Дыхание (`idle`) — СВОЯ ось, доступная в любой позе. Поза задаёт лишь умолчание: поднятый дышит, лежащий нет | `plane.test.ts` |
| Явное `idle` перебивает умолчание позы в обе стороны: лежащая карта дышит, поднятая стоит | `plane.test.ts` |
| Дышит не только карта: фишка и фигура — тем же законом, тем же пресетом | `tableElement.test.ts` |
| Условие сна цикла идёт по САМОМУ дыханию, а не по позе: неподвижная поднятая карта отпускает цикл | `tableElement.test.ts` |

## Модель: тень

| правило | сторож |
|---|---|
| Один закон на все предметы. Форма (прямоугольник карты, эллипс фишки) — параметр, а не второй файл | `plane.test.ts` |
| Лежащий предмет отбрасывает тень СВОЕГО размера, ни пикселем больше | `plane.test.ts` |
| Тень едет в ТУ ЖЕ сторону, что предмет. Высоту показывает ЗАЗОР, а не встречное движение | `plane.test.ts` |
| `attach` — режим, а не число: `element` (приклеена, размер постоянный) или `table` (лежит, растёт и отдаляется). Промежуточного не бывает | `plane.test.ts` |
| Тень ВЫВОДИТСЯ из состояния предмета каждый кадр. Отдельных «теневых анимаций» под каждый эффект нет | `tableElement.test.ts` |
| Маска эффекта (горение, шреддер) РЕЖЕТ форму тени, а не подменяет её: у круглой фишки подмена превращала тень в прямоугольник | `plane.test.ts`, `tableElement.test.ts` |
| Тени одного слоя сливаются в ОДНУ маску: иначе в пересечениях темнеют. Между слоями — не сливаются | — |
| У кнопки тень своя, вне общего пасса: в общей маске она затемняла бы карты под собой | — |
| Форма тени берётся у САМОГО предмета, а не у его типа: тень фигуры — ЕЁ КАРТИНКА, снятая с визуала. «Контур фигуры вообще» дал бы коню тень пешки, а машине — тень поезда; обводка по альфе — та же выдумка, только ступеньками | `tableElement.test.ts` |
| Своего света у предмета не бывает: форма — его, а смещение и рост общие. Растянутая вбок тень рядом с картой, у которой тень под ней, читается как чужая | `plane.test.ts` |
| Снимок визуала делается ОДИН РАЗ на вид предмета и кэшируется: он рисует в текстуру и читает её обратно — в кадре такому места нет. Снимок ОДИН и на тень, и на пыль-цензуру | — |

## Борда: разметка круглого стола

| правило | сторож |
|---|---|
| Разметка зоны КРУПНЕЕ карты (полтора размера): ячейка задаёт разметку и разнос слотов, карта рисуется своим размером и в ячейке центрируется. Карта в ячейке по себе читается великаном в тесном кружке | `ringBox.test.ts` |
| Между периметром центра и внешним кругом — минимум ТРИ ширины карты: в кольцо кладут свободные стопки, и им нужно место | `ringBox.test.ts` |
| Кольцо считается по ФАКТИЧЕСКОМУ габариту центра (он живой: радиальный круг растёт с числом жителей), а не по числу из спеки — `cell` внешней зоны работает как минимум | `ringBox.test.ts` |
| Внешний круг ровный: бокс квадратный даже при прямоугольном центре, и меряется по большей стороне центра | `ringBox.test.ts` |
| Круг стола стартует ПРОСТОРНЫМ: размечен минимум «как под 4 карты», а не точкой, в которую неудобно целиться. Число мест минимум перебивает, если игроков больше | `layouts.test.ts`, `ringBox.test.ts` |
| У круга есть ПОТОЛОК: до него он растёт с числом карт, дальше стоит, а карты ужимаются по нему плотнее (нахлёст веером). Иначе каждая новая карта раздувает стол и утаскивает за собой внешний круг, а масштаб проседает | `layouts.test.ts`, `ringBox.test.ts` |
| Поведение круга — ПРЕСЕТ (`ringPresets.ts`): `grow` (без предела) и `capped` (просторный старт + потолок) — данные под именем, а не ветка в билдере. Песочница сидит на `capped`, витрина показывает оба рычагом | `ringBox.test.ts` |

## Не работает

Известных поломок нет. Три прежних места закрыты 2026-08-02 (см. `git log`):

- тень фигуры была пятном, а не её силуэтом. Альфа-пасса маски так и нет — и не понадобился:
  снимок визуала превращается в КОНТУР по альфе (`ui/silhouette.ts`), а контур общий пасс теней
  принимает и так. Проверено глазами: у коня тень с мордой и ушами, у пешки — с круглой головой;

- дроп в слот на доске — причина оказалась вне `BoardZone`: команда `move` не переставляла ДОМ, и
  возврат из драга отыгрывал перемещение назад; плюс слот выбирался телом фигуры, отстающим от
  пальца. Проверено руками: пустая клетка, занятая (swap), запрет по правилу;
- панель «Код» — подписывалась на канал позже, чем превью присылало код. Берёт `channel.last()`.

**Важно про проверку:** `.storybook/manager.tsx` подхватывается только при СТАРТЕ Storybook.
Правку панели на уже запущенном сервере не увидеть — поднимайте инстанс заново.
