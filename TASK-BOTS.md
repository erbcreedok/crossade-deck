## Решено владельцем — не переспрашивать

1. **Бот ходит в ту же дверь, что человек**: `table.act(botKey, {t:"drop", id, to})` → `follow` → `resend`.
   Ни `table.ts`, ни `script.ts`, ни судья, ни протокол клиента (`PROTOCOL`) не меняются. Ход бота
   летит по экранам как обычный диф. Не через `execute` (он ставит `busy` и блокирует людей).
2. **Бот верит столу, а не памяти.** Перед ходом читает физику: круг в порядке положения
   (`piles.get("ring").cards` — нижняя первая), свою руку. Никаких собственных счётчиков карт.
   Админ может переложить что угодно руками — бот читает результат.
3. **Ход — только карта между СВОЕЙ рукой и кругом.** Из своей руки в круг — сходил; из круга в свою
   руку — взял. Всё остальное (админ переложил из чужой руки, снял лок, дал карту соседу) — уборка
   стола, очередь не сдвигает.
4. **Очередь — от последнего настоящего хода, по рассадке от крупье** (`clockwise`, `dir` последней
   раздачи). Закрыл круг положенной картой — открывает он же; разобрали — следующий за последним
   взявшим (`nextOpener` в `krest.ts`). Тень судьи хранит только «чей ход» и порог круга.
5. **Бот ходит, когда стол замолчал**: очередь его И 2 секунды без намерений и без замков. Пока
   люди спорят и админ правит руки — ждёт.
6. **Легальные ходы даёт тень** (`allowed`): список `lay:<id>` × N и `take`. Мозг выбирает ИЗ
   списка — нелегальный ход невозможен по построению.
7. **Чужие руки бот не видит.** Сервер знает всё, мозгу отдаёт только публичное: круг, свою руку,
   размеры чужих рук, факты из журнала. Иначе это чит.
8. **Судьи за столом по-прежнему нет.** Стол не начинает запрещать ходы людям. Бот — единственный,
   кто слушает тень. Бот не поправляет людей.
9. **Мозги — несколько, разных, за одним интерфейсом.** У каждого бота свой экземпляр.
   Упал / не уложился в дедлайн / вернул не из списка — ходит скриптовый запасной.
10. **Не добавлять UI, которого не просили.** Выбор мозга — через команду `bots` (телеграм-бот),
    кнопка у крупье — только по слову владельца.
11. Живой стол `:2590` перезапускать ТОЛЬКО `launchctl kickstart -k gui/$(id -u)/com.crossade.table`,
    потом проверить `curl https://crossade-deck-server.fly.dev/relay/table` → `up:true` и `/t` → 200.
    Пробный сервер — на свободном порту (2611) с
    `CROSSADE_DB_FILE=":memory:" TABLE_SECRET=dev TELEGRAM_BOT_TOKEN=test TABLE_GUESTS=1 TABLE_RELAY_URL= TABLE_PUBLIC_URL=`.

## Устройство

```
                 факты (krestMemory)  ─┐
журнал ходов ──►                       ├─► Brain.choose(legal, view, profile) ─► Move
тень (match) ──► легальные ходы (allowed) ─┘        │
                                                    ▼
TableRoom.nudgeBots() ── таймер «тишина 2 с» ── table.act(bot, intent) ── follow ── resend ── nudgeBots()
```

### `Brain`

```ts
interface Brain {
  /** Выбор из legal. Дольше deadline / не из списка — комната берёт запасной. */
  choose(legal: readonly Move[], view: BotView, profile: Profile, deadlineMs: number): Promise<Move>;
}
type Move = { t: "lay"; id: string } | { t: "take" };
interface BotView {
  ring: Face[];                 // низ → верх
  hand: { id: string; face: Face }[];
  others: { chair: string; name: string; cards: number }[];   // по рассадке от бота
  closesIfLay: boolean;         // положу — круг закроется, открываю я
  openerIfTake: string | null;  // возьму — кто откроет следующий
  facts: Facts;                 // из krestMemory
}
```

Стратегия и тип игрока — **параметры**, не код: `Profile` = короткий текст для ИИ-мозга + веса для
скриптового. Четыре профиля на старт (владелец подтверждает или правит):
**копитель** (бережёт козыри/джокеры, берёт дешёвое), **закрывала** (играет на закрытие круга,
чтобы открыть самому и скинуть мусор), **агрессор** (бьёт всегда, давит старшими),
**новичок** (тратит козыри рано, берёт не глядя). Плюс сила: лучший ход / семплирование по
вероятностям / нижняя половина.

### `Facts` — `games/krestMemory.ts`, чистый, из журнала настоящих ходов

- у кого сколько карт;
- кто брал и на какой карте сверху → «нет масти X старше Y» / не потратил козырь;
- кто чем бил: клал крести, бил козырем, никогда не бил крести;
- что вышло из игры по мастям, козыри, джокеры, шестёрки;
- сколько карт до закрытия круга, кто закроет, если положит сейчас.

Считает сервер, числами; мозгам отдаётся готовое (Jev и LLM плохо считают).

### Мозги

| мозг | как | заметки |
|---|---|---|
| скрипт `greedy` | чистая функция, веса из профиля | база и запасной для всех |
| скрипт `random` | любой легальный | для тестов и «новичка» |
| **Jev** (TypeSafe AI) | `choice` из `legal`, state = `BotView` + профиль текстом; 70–500 мс | вероятности по вариантам → сила бота одной настройкой. Прямой API `POST api.typesafe.ai/v1/systemone` (ранний доступ) или Vercel AI Gateway `typesafe-ai/jev`. Ключ — через env, как `TELEGRAM_BOT_TOKEN`; никогда в код и логи |
| Ollama | `POST localhost:11434/api/chat`, JSON «номер хода» | стоят `qwen2.5:3b`, `qwen2.5:1.5b`, `llama3.2:1b`; в крестового играют слабо; Ollama.app сейчас не запущен; грузит тот же Мак, что живой стол — только на пробном, пока не измерена нагрузка |
| Claude / Gemini API | как Ollama, по ключу | когда нужен «умный»; платно |

Каталог мозгов — рядом с `refereeOf` в `desks.ts` (комната по-прежнему не знает, какая игра:
закон `the-runtime-knows-no-game`).

### Второй слой — агент-игрок через MCP (отдельная ступень)

stdio-MCP-сервер `crossade-table` с тремя тулами: `look(room)` (стол глазами бота + чей ход),
`moves(room)` (легальные ходы от тени), `play(room, move)`. Агент — Antigravity (конфиг
`~/.gemini/config/mcp_config.json`), Claude Code, Ollama-цикл — садится гостем и играет. Только
пробный сервер (`TABLE_GUESTS=1`); для живого стола боту нужна своя подписанная дверь (`TABLE_SECRET`).
Не постоянный бот: запускается руками, думает 10–30 с/ход, ест квоту.

## Ступени (каждая — коммит, зелёные `tsc --noEmit` + vitest сервера)

1. **Тень считает по столу.** `krestReferee`: руки и круг перечитываются из `Seats` перед каждым
   ответом; в памяти только `turn`, `threshold`, `closer`. Очередь — по правилу 3–4 (свой ↔ круг;
   чужое — уборка). Сторожа: кейс владельца — «Раймондо взял 7 вместо 6, админ вернул 7 на круг и
   дал ему 6 → ход следующего, круг = [7]»; ход из чужой руки очередь не двигает; карта из колоды
   в руку не ломает партию.
2. **`legalMoves` + `BotView` + `krestMemory`.** Чистые модули, таблицы случаев. Сторож: в
   `BotView` нет чужих карт (структурно — тип не имеет поля).
3. **`nudgeBots` в комнате + скриптовый мозг.** Сторожа в `TableRoom.test.ts` с фейковыми часами:
   бот ходит после хода человека; не ходит в песочнице; два толчка — один ход; не ходит, пока
   `busy` / есть замок / прошло < 2 с тишины; после рестора продолжает; отказ стола — в журнал,
   повтор на следующем толчке. Playwright-сторож: карта бота летит на экране.
4. **Профили и сила.** Команда `bots` → `{ n, brain?, profile? }` (контракт + `readCommand` +
   `bot/src/table/orders.ts`). Существующее `bots {n}` работает как раньше.
5. **Jev.** Мозг + дедлайн + запасной; ключ из env; тест с подменённым `fetch`. Проверить на
   пробном сервере с реальным ключом — ключ у владельца.
6. **Ollama** (только пробный) — тот же каркас.
7. **MCP `crossade-table`** — отдельный пакет, три тула, сторож на контракт.

Ступени 1–3 — ядро, без них ничего дальше. 5–7 — по одной, порядок за владельцем.
