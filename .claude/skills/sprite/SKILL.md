# /sprite — заказ спрайта

Заказ — по ОДНОЙ части. Набор целиком не обязателен: часто нужна только голова, или только шапка. Типичный ход:
голова → не понравилась → другая голова → понравилась → по ней тело, ноги, шапка (`--like`).

## 1. Уточнить — ты и есть тот, кто уточняет

Прежде чем гонять agy (минуты, до получаса), убедись, что известно всё ниже. Чего нет в брифе и нельзя уверенно
вывести — спроси ОДНИМ `AskUserQuestion` (до 4 вопросов, варианты с «(Recommended)»), не по одному:

| что | варианты | по умолчанию, если ясно из слов |
|---|---|---|
| часть | голова · шапка/причёска · тело · ноги | «лицо», «по фото», «голову» → голова |
| 2D или 3D | 2D — плоская, как карта (лицо и спина); 3D — как в Doom (6 сторон: + бок, верх, низ) | «как карта/король» → 2D; «как крестоносец/бот» → 3D |
| на основе чего | с нуля · по фото · по готовой части (`--like <папка>`) | «к этой голове», «в том же стиле» → последняя понравившаяся |
| свои цвета | нет · какие (шерсть, кожа) — не перекрашиваются расцветкой игрока | нет |

Не спрашивай то, что уже сказано, и не спрашивай «запускать ли» — запуск и есть ответ на заказ.

## 2. Запустить (в фоне)

```
cd server && node scripts/sprite.mjs --id <id> --slot head|hair|body|legs --look 2d|3d [--like <папка>] [--photo <файл>] [--keep "#hex,..."] "бриф"
```

- `--id` — латиница, коротко по смыслу; части одного персонажа — одна папка (`pirate`: `front-head.svg`, `front-body.svg`…).
  Другая попытка той же части — новая папка (`pirate-2`), чтобы прежнюю можно было сравнить или вернуть.
- `--photo` — фото из чата сохрани в scratchpad и передай путь. Любое фото можно — решение владельца. В репо оно не попадает.
- `--sides 1|2|4|6` — вместо `--look`, если сказано точно (1 — всегда к камере; 4 — без верха и низа).
- Запуск — `run_in_background`; несколько частей одного персонажа можно запускать одновременно, если основа (`--like`) уже готова.

## 3. Показать

Вывод: `ГОДНО` + `лист: …-sheet.png` (все стороны в трёх расцветках) или `НЕ ГОДНО` со списком бед (скрипт уже сам дал agy
два круга на исправление — дальше перезапуск с уточнённым брифом). Лист посмотри сам (Read) и отправь владельцу
(SendUserFile) с одной строкой: что это и что дальше («по ней тело и ноги?»).

## 4. В каталог — только после «да»

- копия `design/persona/skins/<id>/*.svg` → `server/table-client/skins/<id>/`;
- строка в `PARTS` (`server/src/table/skins.ts`): `art: { kind: "file", dir: "<id>" }`, `views` — нарисованные,
  `mirror: SIDE_MIRROR` если есть `right`; `facing`: 1 сторона — `camera`, 2D — `tilt`, 3D — `view`;
  собран персонаж целиком — ещё набор в `SETS`;
- кому открыть: по умолчанию новая часть никому; выдать — `grantParts` (`db/tableOwnedRepo.ts`) или награды (`rewards.ts`);
- в `server/`: `npx tsc --noEmit`, `npx tsc --noEmit -p table-client`, `npx vitest run`; коммит; `launchctl kickstart -k gui/$(id -u)/com.crossade.table`.

Отвергнутые попытки (`pirate-2` и т.п.) — удалить папку после выбора, в репо не коммитить.

То же самое владелец может делать сам — страница хозяина `/table/admin`, вкладка «agy» (`server/src/table/spriteJobs.ts`):
заказ, ход в логе, лист, «В каталог» (без выката — часть ложится в `table_parts`), «Другую», «По ней — ещё часть», «Удалить».
Принятые оттуда рисунки лежат в `server/table-client/skins/<id>/` незакоммиченными — закоммить, когда владелец скажет.

Если agy падает с «command permission … auto-denied» — он пытался запускать терминал; задание это запрещает, просто перезапусти.
