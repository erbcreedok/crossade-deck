# @crossade/bot

Telegram-бот Crossade: управляет столами (комнатами карточного стола) и открывает их в Mini App.
Работает через long polling — вебхуков не ставит; процесс должен быть ровно один на токен.

## Где живёт

На сервере Voyager как user-сервис `crossade-bot` (`~/crossade-deck/bot`, рядом лежит `~/crossade-deck/server`:
бот берёт из него контракт и типы стола). Какой машине принадлежит бот, видно на странице «Узлы»
у хозяина стола (Mini App «Все столы»): бот сообщает о себе столу каждые 30 секунд (`src/table/node.ts`).

```
npm run dev --workspace bot     # локально: tsx watch
npm test --workspace bot
```

## Переменные (`bot/.env`)

| переменная | что |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота из BotFather; обязателен, никогда не коммитится и не пишется в логи |
| `TABLE_SECRET` | общий с сервером стола и реле секрет; без него столы выключены |
| `TABLE_RELAY_URL` | реле (Cloudflare Worker): знает по маяку, где сейчас стол, и держит постоянный адрес `/t/` |
| `TABLE_SERVER_URL` | вместо реле — прямо на сервер стола (разработка на одной машине) |
| `TABLE_APP_NAME` | короткое имя Mini App стола; без него ссылки в группах и inline ведут в браузер |
| `TABLE_MENU_APP` | `1` — кнопка меню «Мои комнаты» открывает мини-апп без комнаты |
| `TABLE_CHATS_FILE`, `TABLE_ROOMS_FILE` | где бот помнит чаты со столами и комнаты (по умолчанию `bot/data/`) |
| `NODE_ID`, `NODE_REGION` | имя и регион этого узла на странице «Узлы» (по умолчанию имя машины и `home`) |

Один раз в BotFather: `/newapp` → имя `table` → URL `<TABLE_RELAY_URL>/t/`; `/setinlinefeedback` → Enabled.

## Команды

- `/room [название]` — открыть комнату в этом чате; `/rooms` — комнаты чата: вход, «Переименовать», «Закрыть».
- `/records` — записи сыгранных партий; `/app` — открыть комнату в приложении (в личке); `/admin` — все комнаты (хозяин).
- `/sticker`, `/stickers` — набор стикеров; `/menu` — меню комнаты.
- `@бот` в любой переписке — карточка нового стола.
- Стол выключен или перезапустился — бот сам пишет в чаты, чьи столы закрылись; без стола отвечает «Столы сейчас недоступны».
