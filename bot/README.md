# @crossade/bot

Telegram-бот: создаёт стол на сервере Crossade Deck и раздаёт ссылку на него в хабе.

## Запуск

```
cp .env.example .env   # заполнить TELEGRAM_BOT_TOKEN
npm run dev --workspace bot
```

Бот работает через long polling — вебхуки не ставит и в сеть его никто, кроме владельца, не
запускает.

## Переменные (`bot/.env`)

| переменная | обязательна | по умолчанию | что |
|---|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | — | токен бота из BotFather |
| `SERVER_URL` | нет | `http://localhost:2567` | адрес сервера Crossade Deck (`POST /rooms`) |
| `HUB_URL` | нет | `http://localhost:9569` | адрес хаба, куда ведёт ссылка на стол; запасной, если `HUB_TUNNEL` выключен или скрипт не смог ответить |
| `HUB_TUNNEL` | нет | `0` | `1` — перед каждой ссылкой спрашивать свежий адрес у `scripts/hub-tunnel.sh` (быстрый Cloudflare-туннель на локальный хаб, см. `deploy/local/README.md`) вместо статичного `HUB_URL` |
| `TELEGRAM_APP_NAME` | нет | — | короткое имя Mini App из BotFather; без неё кнопка в группах ведёт прямо на хаб, а не через `t.me/<bot>/<app>` |

Токен никогда не коммитится и не пишется в логи.

## Команды

- `/start` (в личке) — три кнопки с играми, после выбора бот создаёт стол и присылает ссылку.
- `/cards`, `/chess`, `/nardy`, `/new <игра>` — то же самое одной командой, работает и в группах.

В личке кнопка «Играть» открывает стол как Mini App (`web_app`) прямо в Telegram. В группах
Telegram не показывает `web_app`-кнопки, поэтому там кнопка — обычная `url` на прямую ссылку Mini
App (`https://t.me/<bot>/<app>?startapp=<code>`), если `TELEGRAM_APP_NAME` настроен; в любом случае
под кнопкой есть текстовая ссылка на хаб для браузера.

## Настройка прямых ссылок из групп (один раз, в BotFather)

1. `/newapp` → выбрать своего бота → короткое имя `play` → Web App URL = `HUB_URL`.
2. Задать `TELEGRAM_APP_NAME=play` в `.env` бота (или другое короткое имя, если выбрано другое).

Адрес самого хаба после этого можно менять без похода в BotFather: `web_app` в личке и ссылка под
каждым столом берут его заново при каждой команде (`resolveHubUrl` — `HUB_URL` либо, при
`HUB_TUNNEL=1`, свежий ответ `scripts/hub-tunnel.sh`); кнопка меню (`setChatMenuButton`) — один раз
при старте бота.

## Привязка Telegram к аккаунту

Профиль в хабе показывает ссылку `t.me/<бот>?start=<код>`. Человек жмёт «Запустить», бот говорит
серверу «этот код принёс вот этот chat_id» (`POST /auth/telegram/claim`), и страница логинится сама.
Ни номера, ни @username, ни предыдущего `/start` знать не нужно.

| переменная | где | что |
|---|---|---|
| `TELEGRAM_LINK_SECRET` | и у бота, и у сервера | общий секрет; подтвердить привязку может только наш бот |
| `TELEGRAM_BOT_USERNAME` | у сервера | как зовут бота — из этого собирается ссылка |

Без любой из них путь просто не предлагается: сервер отвечает `503`, а в профиле кнопки нет —
кнопка без двери за ней хуже её отсутствия.

Код одноразовый и живёт пять минут; на аккаунт — не чаще одного в полминуты.

## Столы для HTML-клиента (`src/table/`)

Отдельный клиент стола живёт на маке владельца (`scripts/table-mac.sh`), а бот управляет его
комнатами. Комната — без кода, по подписанному id; живёт, пока жив сервер стола; в одном чате их
может быть сколько угодно.

- `/table [название]` — открыть стол в этом чате (группа или личка с ботом).
- `/tables` — столы чата: вход, «Переименовать», «Закрыть».
- `@бот` в любой переписке — карточка нового стола первой строкой, над столами дев-кита.
- Сервер стола перезапустился или выключился — бот сам пишет в чаты, чьи столы закрылись.
- Сервер выключен — на всё это бот отвечает «Столы сейчас недоступны».

| переменная | что |
|---|---|
| `TABLE_SECRET` | общий с сервером стола и реле секрет; без него столы выключены |
| `TABLE_RELAY_URL` | сервер на Fly: знает по маяку, где мак, и держит постоянный адрес `/t/` |
| `TABLE_SERVER_URL` | вместо реле — прямо на сервер стола (только для разработки на одной машине) |
| `TABLE_APP_NAME` | короткое имя Mini App стола; без него ссылки в группах и inline ведут в браузер, где без Telegram не пускают |
| `TABLE_CHATS_FILE` | где бот помнит чаты со столами (по умолчанию `bot/data/table-chats.json`) |

Один раз в BotFather: `/newapp` → имя `table` → URL `<TABLE_RELAY_URL>/t/`; `/setinlinefeedback` → Enabled.
